# 贪吃蛇：失控进化 (Snake: Mutation Overdrive)

基于经典贪吃蛇的单机 Roguelike 变异进化游戏。吞噬红/蓝/绿三色基因豆积累连锁，触发变异形态，配合主动技能、特殊豆子与随机强化构筑流派，在无限进化模式中冲击高分。

- 技术栈：React + TypeScript + Vite + Canvas 2D + Web Audio API + LocalStorage
- 无后端、无外部素材，纯浏览器运行

## 开发

```bash
npm install
npm run dev      # 开发服务器
npm run test     # 逻辑与 UI 冒烟测试
npm run build    # 生产构建
```

## 操作

- 方向键 / WASD：移动
- 空格：释放技能
- P / Esc：暂停
- R：结算后重新开始
- 移动端：滑动或虚拟方向键
